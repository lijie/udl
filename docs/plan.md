我准备用一系列的简单 demo 来复习深度学习.
  先准备一个 demo1, 写一个 numpy 版本的, 不依赖其它深度学习库. 再写一个 pytorch 版.

  # demo1 想实现下面这个 toy 功能:
  1. 构造一个原函数 F: y = beta3 + omega3 * cos( beta2 + omega2 * exp( beta1 + omega1 * sin( beta0 +
  omega0 * x) ) )
  2. beta 和 omega 可以取随机值
  3. F 就是我们准备拟合的函数.
  4. 根据上面随机值生成的 F, 我们随机采样一组Data1(x, y), 作为我们的训练数据. 一组Data2(x,
  y)作为测试数据, 注意采样时, 需要引入一点随机误差.
  5. 然后构造一个 N-layer, D-维的深度神经网络, 使用上面的Data1训练数据来训练一个深度网络, 然后使用
  Data2来验证我们的网络.

  # 注意点
  1. 作为用来复现的 demo, 代码需要详细注释, 易懂. 且引入足够多的 log 辅助观测.
  2. 函数图像尽量都绘制出来, 方便有几何层面的只管感受.
  3. 如果可能, 最后可以把 原函数/训练数据集/神经网络训练后的测试数据输出 都集中绘制在一张图像上方便对照.
  4. 其它方便理解, 观测的特性你可以自主决策引入.
